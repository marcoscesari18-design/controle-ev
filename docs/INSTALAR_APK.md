# Como instalar o APK no celular Android

O APK é o arquivo de instalação do aplicativo. Como ele não vem da Play Store,
o Android pede uma autorização extra na primeira vez. É seguro: o aplicativo
não acessa a internet.

## Passo a passo

1. **Copie o APK para o celular**
   - Se gerou pelo EAS Build: abra o link de download **no navegador do
     celular** e baixe o arquivo; ou
   - Baixe no computador e envie ao celular por cabo USB, WhatsApp (enviar como
     documento) ou e-mail.

2. **Abra o arquivo baixado**
   - Puxe a barra de notificações e toque no download, ou
   - Abra o aplicativo **Arquivos** e localize a pasta *Downloads*.

3. **Autorize a instalação de fontes desconhecidas**
   - O Android exibirá algo como: *"Por segurança, seu telefone não tem
     permissão para instalar apps desconhecidos desta fonte"*.
   - Toque em **Configurações** → ative **Permitir desta fonte** → volte.
   - Essa permissão vale só para o aplicativo usado para abrir o APK
     (ex.: Chrome ou Arquivos).

4. **Toque em Instalar** e aguarde.

5. **Pronto!** O ícone **Controle EV** aparecerá na lista de aplicativos.
   O app abre vazio, pronto para os seus primeiros registros.

## Possíveis avisos

| Aviso | O que fazer |
|---|---|
| "App foi criado para uma versão mais antiga do Android" | Pode ignorar e continuar. |
| Play Protect: "Verificar app?" | Toque em **Instalar mesmo assim**. O aviso aparece porque o app não veio da Play Store. |
| "Arquivo corrompido" | Baixe o APK novamente — o download pode ter sido interrompido. |

## Atualizando para uma versão nova

Basta instalar o novo APK por cima. **Os dados são preservados**, pois ficam no
banco interno do aparelho. Mesmo assim, exporte um backup antes
(Configurações → Exportar backup) por segurança.

## Desinstalando

Ao desinstalar o aplicativo, **todos os dados são apagados junto**. Exporte um
backup JSON antes se quiser guardá-los.
